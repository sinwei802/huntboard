# evidence-gate


## 何時用

- 任何「我想做下一動作／下一假設」之前。
- 相位切換（初勘→深挖、深挖→身分、身分→域內）的關卡。

## 要驗證什麼

1. 當前假設是否寫成**可證偽**的一句話（不是願望）。
2. 支持該假設的證據是否**已觀測到**（題面／掃描／授權內回應），而非模型「覺得像」。
3. 下一動作是否被這張門允許；不被允許則停或換假設。

## 證據長什麼樣

最低門檻（三選結構，缺一不可升級）：

| 元件 | 合格例子（抽象） |
|---|---|
| 觀測 | 端口／協定／錯誤碼／權限拒絕訊息／匿名可讀主題（具體值來自題面） |
| 解釋 | 「因此假設 X 仍可能成立」——與觀測有因果，不是口號 |
| 可否複核 | 另一人（或下一回合）能依同一觀測重做判斷 |

不合格（門未開）：

- 只有類比（「別台機也這樣」）或只有 CVE 號沒有版本／產品吻合證據。
- 只有「網路上有人這樣打」而本地無對應指紋。

## 死路怎麼標

- 假設寫得出、觀測對不上 → `DEAD:hypothesis-mismatch`，關閉該假設，保留觀測。
- 觀測有、但無法形成可證偽假設 → `DEAD:no-falsifiable-claim`，停在蒐證，不提案利用級動作。
- 需要身分卻零身分來源 → `DEAD:no-identity`，禁止開「域內／AD 刀」類提案。

## 去哪查

- 本庫：`dead-path-mark`、`local-sense-memory`。
- 方法：可證偽假設、證據門檻（公開方法論即可，不指向利用庫）。
- **不把**「有沒有 PoC」當證據門通過條件。
