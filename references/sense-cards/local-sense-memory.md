# local-sense-memory

> **繁中**：本地 sense 記憶：本場已見事實如何回寫與複用（方法層）。



## 何時用

- 開場建戰情、回合結束收斂、或發現「模型會搜但沒 sense」時。
- 決定一則資訊進**本地狀態**還是丟回雲端搜尋即可。

## 要驗證什麼

1. 這則資訊是否影響「該不該打／打哪／怎樣算打過」？是 → 本地該記；否 → 不必進 playbook／戰情。
2. 記的是**決策與證據**，還是手法步驟？（後者不准進本庫。）
3. 下一手能否只靠本地紀錄接續，而不靠聊天記憶？

## 證據長什麼樣（本地應持久化的形狀）

| 要記 | 不要記 |
|---|---|
| 授權範圍與紅線 | payload／PoC／逐步攻擊 |
| 當前相位與未關門檻 | 「感覺下一刀是 X」無證據 |
| 開放假設＋對應觀測 | 從 writeup 抄來的路徑 |
| 死路／GAP 標記 | 整份工具輸出無摘要 |
| 產品指紋與版本（若有） | 無關的長篇網文全文 |
| 已強制載入哪張 PB 卡 | 厚手法 cookbook 全文 |

一句口訣：**雲端＝可能；本地＝准否與進度。**

## 死路怎麼標

- 需要決策但本地空白 → `GAP:no-local-playbook`（盲測已證實的缺口類型）。
- 本地只堆工具 raw log、無假設／門檻 → `GAP:state-unstructured`，先整理再往下。
- 把利用步驟寫進 vault → **違規**；刪除或改寫成證據／查法後再存。
