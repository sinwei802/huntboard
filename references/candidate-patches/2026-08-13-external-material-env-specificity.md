# Candidate Patch: 2026-08-13 — 外部材料環境特定性

## 問題軸
外部 writeup/PoC 中的技術結論（執行身份、預設值、啟用狀態等）是否可直接移植到不同目標？

## 心法
**否。** writeup 裡的結論是作者環境的事實，不是通用前提。結論的成立條件依賴目標環境（服務帳號、安裝方式、版本、設定）時，必須在當前目標上獨立驗證後才能用來規劃攻擊路線。

## 失敗模式
讀到 writeup 的環境特定結論 → 直接套用到不同目標 → 規劃攻擊路線 → 實際執行後發現前提不成立 → 整條路線無效 → 浪費回合

## 泛化測試
- (i) n=1（本次事件）→ 不足，留隔離區
- (ii) 反例：CVE 描述「affects versions prior to X」是否算環境特定？→ 否，版本範圍是 CVE 的事實陳述，不是環境結論；但「exploit 以什麼身份執行」「服務預設是否啟用」「路徑是否可寫」這類才是環境特定
- (iii) 去具體化後 = 「技術結論的適用範圍是否包含環境維度」→ 問題軸成立
