# Candidate Patch: 2026-08-13 — 授權動作完成即停

## 問題軸
授權動作成功後，授權是否自動延伸至「自然下一步」？

## 心法
**不延伸。** 使用者具名授權的動作一旦有結果返回（成功或失敗），授權已用盡。該動作產生的新攻擊機會（新 session、新憑證、新 RCE 通道）只形成新假設與建議，不形成新授權。「做 X 成功 → 用結果做 Y」永遠是新 STEP。

## 失敗模式
exploit／密碼變更／認證繞過成功 → 產生新攻擊面 → agent 把「自然的下一步」當授權延伸 → 自行串下一個目標動作 → 越線

## 泛化測試
- (i) n=1（本次事件）→ 不足，留隔離區
- (ii) 反例：使用者說「然後登入看看」是否算延伸授權？→ R3 判準：只有當前訊息具名的動作才算，「然後」可能授權緊接的下一步，但不授權再下一步
- (iii) 去具體化後 = 「授權動作完成後授權邊界是否延伸」→ 否，這是斷言不是問題軸 → 需重新表述為問題軸：授權時效在動作完成時的邊界
